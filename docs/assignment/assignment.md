# CSC 2210 – Final Term Project

## Overview
The term project is your chance to design and implement something substantial in C++.
You may work individually or in pairs (confirm partners with me).
Your goal is to plan, build, and present a working program that demonstrates strong design, effective use of C++ features, and good coding practices.

## Expectations
By the end of the term, you should:

1. Design & Plan
    - Submit a short-written proposal (see format below).
    - Define the problem, scope, and main features.

2. Develop & Document
    - Implement the project using C++.
    - Use Git/GitHub (or other VCS) to track changes.
    - Include clear inline comments and a README describing build/run instructions.

3. Present
    - Give a 3-minute lightning talk on your scheduled date.
    - Demo your progress or final build and share one lesson learned.

## Proposal Format (Due Week 6)

Submit a short document (1–2 pages) with:
- Project Title
- Team Members (if any - to reduce the workload (for groups, the scope of the project should cover more functionalities))
- Objective / Problem Statement
- Key Features (bulleted list)
- Tools/Libraries you expect to use
- Timeline – major milestones
- Potential Challenges or questions

Upload as PDF to Canvas under “Term Project Proposal.”

## Deliverables
- Proposal (Week 6)
- Source Code & README (Finals week)
- Lightning Talk (see posted schedule)

## Grading Rubric (100 pts total)
|Category                       |Points |Description                    |
| :---------------------------- | ----: | :-----------------------------|
|Proposal & Planning            |15     |Clear objective, realistic scope, well-structured timeline|
|Design & Implementation        |35	    |Sound program structure, appropriate use of C++ features (classes, STL, memory management, etc.)|
|Functionality & Testing	    |25	    |Code compiles, runs correctly, and is tested with representative cases|
|Documentation & Style	        |15	    |Clean, readable code, meaningful comments, complete README|
|Presentation (Lightning Talk)	|10	    |Engaging, on-time, explains project and key lesson|

Late work follows standard course late-submission policy unless otherwise arranged.

## Use of Coding Agents / AI Tools
You may use coding agents or AI assistants to save time or brainstorm, but you are responsible for:
- Understanding all code you submit
- Being able to explain every line during questions
- Ensuring originality and adherence to MSOE academic-integrity standards
